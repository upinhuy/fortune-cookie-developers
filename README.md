## The entry

> A bug found in review is a fortune; the same bug found in production is a bill.

A bug caught in code review feels like luck — the same bug caught in
production arrives as a cost. "Fortune" carries both meanings at once:
the cookie's promise, and the money it saves.

## How it works

`main.ts` is a small deterministic Node/TypeScript program with no
dependencies. It writes the single line above to `/output/entry.txt`
(79 characters, one line), creating the output directory if needed, and
refuses to write anything outside the 1–120 character gate.

Run it with:

```sh
node main.ts
```
